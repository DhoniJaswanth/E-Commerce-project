# 📊 E-Commerce Sales Analysis using Python

A complete Exploratory Data Analysis (EDA) project on the Superstore Sales dataset using Python, Pandas, and Plotly. This project analyzes sales performance, customer behavior, product categories, and business trends to generate meaningful business insights.

---

## 📌 Project Overview

This project demonstrates how to perform data cleaning, preprocessing, feature engineering, and visualization on an e-commerce sales dataset.

The analysis helps answer business questions such as:

- Which months generate the highest sales?
- Which product categories perform the best?
- Which regions contribute the most revenue?
- How do discounts affect profit?
- What are the sales trends over time?
